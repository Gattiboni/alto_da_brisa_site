# knowledge/temas/ — geração legada (abril/2026)

Este diretório é **legado**. Contém a primeira geração da base de conhecimento
por módulo, produzida em abril/2026 a partir dos **slides** do curso (ver D008 e
D010 no `docs/DECISION_LOG.md`).

**Não alimenta o site.** A fonte de verdade ativa do conteúdo das aulas é
`knowledge/aulas/` (ver **D016**). O pipeline de publicação lê `knowledge/aulas/`,
consolida via `scripts/consolidar_temas.py` e escreve em `site/content/temas/`
(saída gerada — nunca editar à mão).

Este material é preservado como referência histórica e como fonte suplementar
(por exemplo, foi a base para o preenchimento da Aula 32 — Viga Baldrame — cujo
tema só existia aqui, nos slides, e não na transcrição de áudio; ver D017).
