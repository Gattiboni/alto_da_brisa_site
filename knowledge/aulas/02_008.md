# Fluxo de Projetos 1/2

O fluxo de projeto de uma casa não é linear — ele passa por várias revisões e ajustes até chegar à execução. Muita gente pula etapas essenciais e vai direto para a obra, o que resulta em custos extras, retrabalhos e, às vezes, até inviabiliza o projeto.

Vamos entender como funciona o caminho correto, do terreno vazio até a casa pronta.

## A Jornada Completa: Do Ponto A ao Ponto B

Imagine que você está no **ponto A** — terreno vazio (ou nem isso ainda) — e quer chegar ao **ponto B**, que é a casa pronta e entregue.

Para sair do A com um pontapé inicial consistente e não ficar ziguezagueando no caminho, você precisa:

- Projetos bem desenhados e revisados
- Impressos e aprovados
- Principais fornecedores já definidos
- Construtor alinhado com os projetos

### O Problema Comum

O que a gente vê no mercado brasileiro:

```flow
Desenvolvimento de Projetos → Execução da Obra
```

E pronto. **Não existe pré-obra. Não existe planejamento financeiro. Não existe estudo de viabilidade.**

O que acontece na prática:
- A pessoa decide construir
- Contrata o arquiteto
- Enquanto ele faz o projeto, já manda alguém limpar o terreno
- Terreno limpo, já cava as fundações
- "Como assim o projeto não ficou pronto? Eu liguei às 5h da manhã pro arquiteto dizendo que o pedreiro chega às 8h!"

Resultado: obra começa sem planejamento → estoura orçamento → para no meio → frustrações infinitas.

## O Fluxo Correto (Segundo a Norma)

O professor Escarvalho (2019) desenhou o planejamento ideal de execução de uma obra. Veja a sequência:

### 1. Estudo de Viabilidade
**Antes** de desenvolver os projetos completos.

O estudo de viabilidade responde:
- **Financeiro:** Você consegue pagar para construir isso?
- **Técnico:** Tem fornecedor? Tem mão de obra especializada na região?
- **Legal:** A prefeitura permite?
- **Terreno:** Dá para fazer o que você quer nesse terreno?

> [!atencao]
> Se você não tem viabilidade comprovada, **não avance para o desenvolvimento dos projetos completos**. Você vai gastar dinheiro em projeto que não conseguirá executar.

### 2. Desenvolvimento dos Projetos
Só após confirmar que é viável.

Aqui entram:
- Projeto arquitetônico (do estudo preliminar ao executivo)
- Projetos complementares (estrutural, elétrico, hidráulico)
- Compatibilização entre todos eles

### 3. Pré-Obra
Antes de começar a obra de verdade:
- Orçamento executivo em mãos
- Cronograma físico-financeiro pronto
- Fornecedores principais já selecionados
- Materiais com prazo de entrega mapeado
- Canteiro de obras planejado

### 4. Execução da Obra
Agora sim, põe a mão na massa.

Com tudo planejado, a execução vira apenas **executar o que foi ensaiado**.

### 5. Pós-Entrega
- Feedbacks
- Banco de dados para construções futuras
- Registro do que deu certo e do que pode melhorar

## Por Que Essa Ordem Importa?

### Exemplo Real: Projeto Sem Viabilidade

Você contrata arquiteto, ele desenha a casa dos sonhos, você aprova, adora. Investe R$ 10 mil no projeto completo.

Aí vai fazer o orçamento executivo e descobre: **vai custar o dobro do que você pode pagar**.

O que fazer?
- Jogar o projeto fora e recomeçar? (perdeu R$ 10 mil)
- Tentar adaptar? (custa quase tanto quanto fazer novo)
- Construir só metade? (frustrante)

**Se tivesse feito estudo de viabilidade antes**, com investimento de R$ 2 mil, teria descoberto isso **antes de gastar os R$ 10 mil no projeto completo**.

### O Ditado Militar

> "Nenhum plano de batalha sobrevive ao contato com o inimigo."
> — General dinamarquês (adaptado)

Tradução para obra: quando você começa a obra, na primeira semana o planejamento já vai começar a entortar. Vão surgir imprevistos.

**Mas pelo menos você tem um eixo para voltar.** Sem planejamento, você fica completamente perdido, sem referência de onde está nem para onde vai.

## O Erro Clássico: Pular o Estudo de Viabilidade

Fluxo errado (comum no mercado):
1. "Vou construir uma casa"
2. Contrata arquiteto
3. Arquiteto desenha
4. Aprova na prefeitura
5. Faz orçamento executivo
6. **Descobre que não pode pagar**
7. Projeto parado, dinheiro investido perdido

Fluxo correto (com viabilidade):
1. "Vou construir uma casa"
2. **Estudo de viabilidade** (é viável? cabe no bolso?)
3. Se sim, desenvolve projetos
4. Aprova na prefeitura
5. Orçamento executivo (ajustes finos)
6. Executa

## Principais Etapas do Estudo de Viabilidade

Quando você faz um estudo de viabilidade, está verificando:

**Viabilidade Financeira:**
- Estimar custo da obra
- Comparar com orçamento disponível
- Aplicar curva ABC para identificar onde economizar
- Fazer ajustes no projeto ainda no papel (barato de mudar)

**Viabilidade Técnica:**
- Existe fornecedor de tijolo ecológico na região?
- Tem mão de obra especializada em steel frame?
- O material chega em quanto tempo?

**Viabilidade Legal:**
- Prefeitura permite construir o que você quer?
- Terreno tem restrições de gabarito, recuos?

**Viabilidade do Terreno:**
- O terreno comporta o projeto?
- Qual o tipo de solo? (SPT)
- Tem desnível que vai encarecer?

> [!dica]
> O estudo de viabilidade custa entre 0,5% a 1% do valor da obra. Parece caro, mas **ele paga a si mesmo** ao evitar que você invista em projeto inexequível.

## Quando as Coisas Podem Mudar

Mesmo com planejamento, imprevistos acontecem:
- Fornecedor atrasa entrega
- Material sobe de preço
- Chuva para a obra por semanas
- Descobre problema no solo

A diferença é que, **com planejamento**, você:
- Identifica o problema rapidamente
- Sabe quais tarefas pode adiantar no lugar
- Recalcula prazos e custos com base em dados
- Toma decisões informadas, não no desespero

**Sem planejamento**, você:
- Não sabe se está atrasado ou no tempo
- Não sabe se está gastando certo
- Não tem alternativas mapeadas
- Age no desespero, tomando decisões ruins

## Resumo: A Sequência Correta

```flow
Levantamento de Necessidades
Orçamento Preliminar :: Ordem de grandeza
Escolha do Terreno
Estudo de Viabilidade (EVF) :: Se inviável, ajuste necessidades/orçamento/terreno antes de seguir
Desenvolvimento de Projetos :: Preliminar → básico → executivo
Aprovação na Prefeitura
Orçamento Executivo
Pré-Obra :: Cronograma, fornecedores, canteiro
Execução
Pós-Entrega :: Feedback, banco de dados
```

## Checklist: Você Está Pronto para Começar a Obra?

Antes de dar a primeira cavada, confirme:

- [ ] Estudo de viabilidade aprovado
- [ ] Projetos executivos em mãos (arquitetônico + complementares)
- [ ] Projetos compatibilizados entre si
- [ ] Aprovação da prefeitura obtida
- [ ] Orçamento executivo finalizado (margem de erro ≤ 5%)
- [ ] Cronograma físico-financeiro pronto
- [ ] Principais fornecedores selecionados e com prazos confirmados
- [ ] Construtor/mestre de obra alinhado com os projetos
- [ ] Canteiro de obras planejado
- [ ] Materiais de longo prazo já encomendados

Se faltou algum item, **você não está pronto**. Volte e complete.
